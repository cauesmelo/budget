# Budget project instructions

- After completing requested changes, run appropriate checks and create a local commit before delivering the result. This is an explicit user preference.
- Include only changes related to the completed work in the commit; preserve unrelated user changes.
- Keep bank statements, personal spreadsheets, backups, and credentials out of version control, as specified in `.gitignore`.
- Push commits to the remote repository when the user requests it.
- Write code identifiers, comments, user interface text, documentation, and commit messages in English. Preserve imported financial data and source-format labels required to recognize bank statements and legacy spreadsheets.
