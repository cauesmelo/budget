# Instruções do projeto Budget

- Ao concluir alterações solicitadas, execute as verificações adequadas e faça um commit local antes de entregar o resultado. Essa é uma preferência explícita do usuário.
- Inclua no commit somente mudanças relacionadas ao trabalho concluído; preserve alterações independentes do usuário.
- Mantenha extratos, planilhas pessoais, backups e credenciais fora do versionamento, conforme o `.gitignore`.
- Envie commits ao repositório remoto quando o usuário solicitar.
